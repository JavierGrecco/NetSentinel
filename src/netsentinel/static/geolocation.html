Qué muestra el mapa: ubicaciones aproximadas de IP públicas registradas como destino en los eventos locales guardados. No inicia captura de tráfico ni resuelve dominios antiguos como si fueran IP observadas. Las direcciones privadas y especiales no se geolocalizan. La geolocalización usa bases GeoIP instaladas en esta computadora, sin API externa. El formulario manual consulta el resolvedor DNS configurado en el sistema, que puede ser remoto.

CONSULTA MANUAL

¿De dónde es la IP de una página?

Ingresá un dominio para consultar su resolución DNS actual y ubicar las IP públicas con la base GeoIP local. Esta consulta no se guarda como evento ni demuestra qué IP se utilizó en visitas anteriores.

Al pulsar el botón, el dominio se consulta al resolvedor DNS del sistema; ese resolvedor puede ser externo. Las coordenadas se obtienen únicamente de la base GeoIP local de NetSentinel.

Preparar la base geográfica local

Descargá GeoLite2-City desde tu cuenta de MaxMind y guardá el archivo autorizado en el directorio de datos local de NetSentinel. Por defecto, en macOS/Linux, es ~/.netsentinel/GeoLite2-City.mmdb. También podés definir NETSENTINEL_GEOIP_CITY_DB con la ruta de la base. NetSentinel no descarga una copia ni transmite IP por su cuenta.

DETALLE SELECCIONADO

Elegí un punto o una IP

Seleccioná un marcador del mapa o una fila de la tabla para revisar los metadatos registrados.

La cantidad de eventos mide registros guardados, no bytes ni paquetes medidos por este mapa. Para una IP asociada a una visita de navegador, se necesita que la fuente haya registrado también la IP destino (por ejemplo, un registro de conexiones autorizado). Si solo hay un dominio, no se deduce retrospectivamente qué IP se usó en ese momento.
