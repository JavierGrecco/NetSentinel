Inventario Monitorización Herramientas Actividad

Módulos independientes de consulta y diagnóstico. Las herramientas se ejecutan solo cuando las solicitás.

Consulta DNS

Consulta las direcciones IPv4 e IPv6 que devuelve el resolvedor configurado en esta computadora.

La consulta es de solo lectura y se realiza al enviarla. Una resolución correcta no demuestra que un dispositivo sea legítimo ni confiable. No ingreses datos privados.

DNS inverso (PTR)

Consulta si el resolvedor del sistema publica un nombre asociado a una dirección IP concreta.

Un PTR puede faltar o estar desactualizado. El nombre devuelto no confirma quién controla la dirección ni que el equipo sea confiable.

DNS configurado en esta computadora

Vista de solo lectura de los servidores DNS que el sistema expone a NetSentinel. No se cambia ninguna configuración.

Leyendo configuración local…

La configuración puede variar por interfaz, VPN o DNS dividido. Esta vista es orientativa y no necesariamente refleja todas las reglas activas del sistema.
