ANTES DE EMPEZAR · UNA SOLA VEZ POR BASE

Prepará el laboratorio aislado

Si todavía no preparaste los datos sintéticos, ejecutá el bloque desde la raíz de esta copia del repositorio. Crea una base aislada con nombre único, genera los CSV y prepara el archivo ficticio para Forense. No sobrescribe escenarios previos: si la carpeta de archivos de prueba ya existe, conservála y usá una copia limpia del laboratorio.

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[test,geoip]"
export NETSENTINEL_DATA_DIR="$HOME/.netsentinel-guided-test-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$NETSENTINEL_DATA_DIR"
python scripts/generate_manual_scenarios.py --device-ip 192.168.56.20
python scripts/seed_manual_test_database.py --device-ip 192.168.56.20
printf "NETSENTINEL_DATA_DIR=%s\\n" "$NETSENTINEL_DATA_DIR"
mkdir -p "$NETSENTINEL_DATA_DIR/forensics-working-copies"
python -c 'from pathlib import Path; import os, hashlib; p=Path(os.environ["NETSENTINEL_DATA_DIR"])/"forensics-working-copies"/"netsentinel-forensic-sample.bin"; p.write_bytes(b"NetSentinel synthetic evidence v1"); print("SHA-256:", hashlib.sha256(p.read_bytes()).hexdigest())'
./run.sh

Importante: no ejecutes este bloque contra tu instalación habitual. Después de preparar la base, mantené esta terminal abierta y seguí los escenarios desde el navegador. Si ya preparaste esta base y el servidor está en marcha, no vuelvas a sembrarla.
01

IMPORTACIÓN

CSV válido y detección de duplicados

Validá que la vista previa no escriba eventos y que repetir una importación no duplique los registros.

  1. Abrí Actividad y seleccioná el dispositivo Dispositivo sintético de prueba.
  2. En la carpeta netsentinel-test-artifacts/manual-scenarios, elegí activity.csv y ejecutá la vista previa.
  3. Confirmá la importación y después previsualizá el mismo archivo otra vez.
Resultado esperadoLa vista previa muestra seis filas válidas; después de confirmar, la repetición identifica duplicados en lugar de crear una segunda copia.
Abrir ActividadNo uses archivos de tus registros personales.

GEOLOCALIZACIÓN

Mapa mundial de IP observadas

Después de importar activity.csv, comprobá que el mapa usa las IP destino guardadas y no inventa posiciones.

  1. Abrí el mapa y revisá el resumen, la tabla y el filtro.
  2. Pulsá Comprobar API para verificar que la app puede leer el resumen local.

Resultado esperadoLa cartografía y la tabla cargan; los destinos sin coordenadas siguen visibles en la tabla, pero no se dibujan como puntos.

Prueba opcional si tenés conexión DNS: en la consulta manual de dominio probá example.com. La pantalla debe aclarar que es una resolución actual y no registrar esa IP como si fuera un evento histórico. Si no tenés conexión, omití ese paso.

04

INTEGRIDAD DE EVIDENCIA

NetSentinel Forense: comparar hashes

Usá exclusivamente la copia sintética preparada en forensics-working-copies. No registres evidencia real en esta prueba.

  1. En el campo de operador, escribí Operador sintético de prueba. Abrí Forense y creá un caso usando los valores de la tarjeta inferior.
  2. En ese caso, registrá netsentinel-forensic-sample.bin como una copia de archivo. Usá el SHA-256 que imprimió la preparación como dato informado por la fuente y completá su origen.
  3. En la ficha recién registrada, abrí Comparar con una copia de trabajo, ingresá solo netsentinel-forensic-sample.bin y marcá la confirmación de que es una copia autorizada. Primero debe coincidir.
  4. Desde otra terminal, exportá el mismo NETSENTINEL_DATA_DIR que imprimió la preparación y ejecutá el comando de abajo. Después repetí la comparación en Forense.

PRUEBAS NEGATIVAS

  1. En la evidencia sintética, volvé a abrir Comparar con una copia de trabajo. Probá el nombre missing-sample.bin y confirmá que es una copia de trabajo autorizada.

TRAZABILIDAD

Después de registrar y comparar la copia sintética, comprobá que el caso conserve el historial de operaciones.

  1. Seleccioná el caso de prueba y descargá el manifiesto de auditoría.
  2. Descargá el expediente consolidado del caso.
  3. Abrí los dos JSON descargados. Comprobá que correspondan al caso sintético y que el historial incluya el registro de evidencia y las comprobaciones realizadas.
Resultado esperadoLos dos archivos JSON se descargan y contienen metadatos del caso y la auditoría relevantes. Un hash o digest del manifiesto ayuda a detectar cambios, pero no es una firma digital ni acredita por sí solo la autenticidad.
