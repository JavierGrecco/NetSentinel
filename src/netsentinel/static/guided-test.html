Prepará el laboratorio aislado

Si todavía no preparaste los datos sintéticos, ejecutá el bloque desde la raíz de esta copia del repositorio. Crea una base aislada con nombre único, genera CSV en una carpeta visible con nombre único y prepara el archivo ficticio para Forense. Imprime ambas rutas. Conserva las carpetas previas y no las sobrescribe.

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[test,geoip]"
export NETSENTINEL_DATA_DIR="$HOME/.netsentinel-guided-test-$(date +%Y%m%d-%H%M%S)-$$"
mkdir -p "$NETSENTINEL_DATA_DIR"
export SCENARIO_DIR="$PWD/netsentinel-test-artifacts/manual-scenarios-$(date +%Y%m%d-%H%M%S)-$$"
mkdir -p "$(dirname "$SCENARIO_DIR")"
python scripts/generate_manual_scenarios.py --output-dir "$SCENARIO_DIR" --device-ip 192.168.56.20
python scripts/seed_manual_test_database.py --device-ip 192.168.56.20 --include-topology
printf "NETSENTINEL_DATA_DIR=%s\\nSCENARIO_DIR=%s\\n" "$NETSENTINEL_DATA_DIR" "$SCENARIO_DIR"

./run.sh

    Qué mirar: Después de importar una vez, repetí la vista previa y compará el resumen de duplicados con el primer resultado. Por qué importa: La idempotencia evita que volver a cargar un mismo archivo distorsione el historial de actividad.
